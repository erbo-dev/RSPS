# Frozen-recipe amplitude challenge

This exploratory diagnostic follows the three existing stages on the same public
development sources. All added-artifact cases in the original five-SNR grid
activate the high95 switch. Consequently that grid cannot alone assess its
transition behavior.

Before observing these additional outcomes, fix four weak-artifact SNR values
at +6, +12, +20 and +30 dB, alongside the original +2, 0, -3, -7 and -15 dB
values as exact reproduction guards. Refit exactly the same original and
real-artifact-augmented decoders as stage two/three. Training augmentation uses
only the original five SNR values. Keep the empirical 95th-percentile threshold
from clean fitting runs unchanged. No threshold or classifier search follows
this challenge.

Report full-coverage errors, HARM using the shared original clean-correct
reference, the fraction activating the augmented decoder, clean errors and
their person-fold dependence. Check old-grid error vectors against the saved
stage-three outcomes, not just against aggregate percentages. This is a
within-source amplitude challenge, not a new independent dataset or proof of
novelty. Weak added artifacts are still constructed from the same processed
chewing windows; natural concurrent EMG and temporal drift remain untested.
