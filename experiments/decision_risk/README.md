# RKNP exploratory extension: artifact-aware decoder selection

This directory is an additive experiment. It does not replace the original
repository study or convert its previously opened groups into a new sealed
test. Read [REPORT_RU.md](REPORT_RU.md) for outcomes and limitations.

The most useful pilot candidate is `high95_switch_augmented`: retain the
original clean-trained CSP/LDA decoder on lower observed 40–80 Hz power and
switch to a second LDA trained on real chewing-artifact mixtures above the
95th percentile of clean fitting-run power. The threshold and CSP are fitted
without the host evaluation run; artifact evaluation people are held out.
This is an exploratory application of augmentation and decoder selection,
not a verified globally novel method. It improves the original five-SNR
contamination grid but can worsen weaker-artifact cases.

## Reproduce

Use Python 3.11 or newer and a new virtual environment. Commands start at the
repository root. The experiment uses MNE/scikit-learn directly, not MOABB.

```bash
python -m venv .venv
.venv/bin/python -m pip install -r experiments/decision_risk/requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m unittest discover -s experiments/decision_risk -p 'test_*.py'
```

For an exact six-person acquisition pilot in a **fresh cache**, download the
public raw recordings with the explicit acquisition option:

```bash
.venv/bin/python experiments/decision_risk/reproduce.py --cache /absolute/path/rknp-pilot-cache --out /absolute/path/rknp-pilot-output --acquire-pilot
```

To reuse an existing complete pilot cache, omit `--acquire-pilot`. No new donor
downloads occur in that mode. Host recordings still download if missing.
Do not treat a cache containing additional donor people as the exact original
six-person pilot. Source IDs and raw MATLAB checksums are recorded in metadata.

For the larger **24-person, two-windows-per-person** development extension,
use a separate cache and output directory:

```bash
.venv/bin/python experiments/decision_risk/reproduce.py --cache /absolute/path/rknp-24-cache --out /absolute/path/rknp-24-output --full-bank
```

This larger command is provided but was **not completed** in this run. It is
not the full 247-window bank, and it does not add a new host evaluation session.
The first acquisition was interrupted by the execution environment; the cached
subset was fixed before candidate outcomes (see AMENDMENT_ACQUISITION.md).
The endpoint must support valid HTTP 206 EDF range responses. Acquisition
refuses incorrect ranges, units, missing channels or >5% donor RMS mismatch.

For the report figure after results exist at the default directory:

```bash
.venv/bin/python experiments/decision_risk/plot_results.py
```

## Experimental stages and files

| Stage | Specification | Implementation | Output |
|---|---|---|---|
| Observable power-based rejection | PROTOCOL.md | run.py | results/ |
| Artifact-augmented decoder | AUGMENTATION_PROTOCOL.md | augmentation.py | results_augmentation/ |
| Fixed high-frequency switch | SWITCHING_PROTOCOL.md | augmentation.py --include-switch | results_switching/ |
| Weaker-amplitude challenge | STRESS_PROTOCOL.md | stress.py | results_stress/ |
| Calibrated decoder choice | SELECTOR_PROTOCOL.md | selector.py | results_selector/ |

`verify_results.py` checks paired source order, unchanged control error vectors,
selector aggregate counts and bootstrap sensitivity along both participant
axes. `RESULTS_AUDIT.json` contains its output. Six mathematical/coverage tests
and two decoder-choice contract tests run in `test_experiment.py`.

Small summaries, protocols, manifests and clean-control tables are committed.
Detailed fold CSVs and per-variant NPZs are generated by the commands and are
included in the accompanying experiment archive. Raw EEG/EDF signals are not
committed. `REPRODUCTION_MANIFEST.json` records code and acquisition checksums
for the reported run. Metadata added after computation does not alter outcomes.

The EDF manual-parser cross-check against MNE is recorded separately in
results/EDF_READER_CHECK.json. The original five-fitting-run decoder exactly
reproduced all nine documented rounded clean accuracies. New candidate
comparisons reserve one additional calibration run and therefore use four
fitting runs; their shared clean baseline differs from that original ledger.

## Data and claim scope

Host: BNCI2014_001, left/right motor imagery, nine T-session recordings,
19 common channels, 250 Hz, 4-second cue-relative epochs. Artifact:
OpenNeuro ds006386, 12 real chewing windows from development people 1–6,
processed through the original 20–80 Hz safety branch before the 8–32 Hz
decoder and 40–80 Hz proxy branches. SNR uses the original fixed 4.4 µV
reference; it is not per-trial decoder-band SNR.

This is controlled addition of separately recorded artifacts. It does not
establish performance during naturally concurrent muscle activity, at the
online causal filter boundary, on hardware, or in clinical use. Public data
are reused across stages; post-outcome follow-ups and availability selection
are disclosed. There is no valid independent confirmatory p-value here.
